Create LoginPage.vue in src/frontend/src/pages/auth/ directory (create the auth/ subdirectory if it does not exist).

Component structure:
1. Template:
   - Centered card layout using q-page with flexbox centering
   - Mobile-responsive: col-12 col-sm-8 col-md-6 col-lg-4
   - q-card with q-card-section for header (t('auth.login')) and form
   - Show session expired alert (q-banner type="warning") when route.query.expired === 'true', using t('session.expired')
   - q-form with @submit.prevent calling handleLogin
   - q-input for email: v-model="form.email", type="email", :label="t('auth.email')", lazy-rules, :rules="[required, validEmail]", :error="hasFieldError('id')", :error-message="getFieldError('id')"
   - q-input for password: v-model="form.password", type with toggle (use isPwd ref), :label="t('auth.password')", lazy-rules, :rules="[required]", :error="hasFieldError('password')", :error-message="getFieldError('password')"
   - Password show/hide toggle using q-icon in template slot append (visibility/visibility_off icons)
   - Submit button: q-btn type="submit", :loading="isSubmitting", :disable="isSubmitting", :label="t('auth.login')"
   - Error display: Show general error message if hasError and not isValidationError using q-banner type="negative"
   - Links section: router-link to /forgot-password (t('auth.forgotPassword')) and /register (t('auth.noAccount') + t('auth.createAccount'))

2. Script setup:
   - Imports: ref, useRouter, useRoute, useI18n, authApi, useErrorHandler
   - const router = useRouter(); const route = useRoute(); const { t } = useI18n();
   - const { setError, clearError, hasError, errorMessage, isValidationError, hasFieldError, getFieldError } = useErrorHandler();
   - Form state: const form = ref({ email: '', password: '' }); const isPwd = ref(true); const isSubmitting = ref(false);
   - Validation rules: const required = val => !!val || t('validation.required'); const validEmail = val => /.+@.+\..+/.test(val) || t('validation.email');
   - handleLogin async function:
     a. clearError()
     b. isSubmitting.value = true
     c. try { const response = await authApi.login(form.value.email, form.value.password, 1); }
     d. Check if response.message === 'check.otp': router.push({ path: '/otp', query: { id: response.data.loginInfoId, redirect: route.query.redirect } })
     e. Else (success): router.push(route.query.redirect || '/dashboard')
     f. catch (err) { setError(err); }
     g. finally { isSubmitting.value = false; }

3. Styling:
   - Use Quasar utility classes (q-pa-md, q-mt-md, q-gutter-md, etc.)
   - No custom CSS needed if Quasar classes used properly
   - Card should have max-width: 400px via style attribute or class

Code standards (from spec):
- Use script setup only (no Options API)
- Plain JavaScript (no TypeScript)
- All text via t() from useI18n
- Use lazy-rules on form inputs
- Use :loading and :disable on submit button
