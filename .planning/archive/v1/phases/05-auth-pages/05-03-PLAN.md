  <action>
Create OtpPage.vue in src/frontend/src/pages/auth/ directory.

Component structure:
1. Template:
   - Centered card layout using q-page with flexbox centering
   - Mobile-responsive: col-12 col-sm-8 col-md-6 col-lg-4
   - q-card with q-card-section for header (t('auth.enterOtp')) and content
   - Info text: q-banner type="info" with t('auth.otpSent') message
   - OTP expiry warning: small text noting "Code expires in 30 minutes"

   OTP input section (6 individual inputs):
   - Container div with class="flex justify-center q-gutter-sm"
   - 6 x q-input, each:
     - ref="otpInputs" (array ref)
     - v-model="digits[index]"
     - maxlength="1"
     - class="otp-digit" (custom class for styling)
     - style="width: 50px; text-align: center; font-size: 24px"
     - input-class="text-center"
     - @input="onDigitInput(index, $event)"
     - @keydown="onKeyDown(index, $event)"
     - @paste="onPaste"
     - :autofocus="index === 0"
     - mask="#" (only allow digits)

   Error display: q-banner type="negative" if hasError
   Loading state: Show q-spinner-dots when isSubmitting

   Resend section:
   - Text: "Didn't receive the code?"
   - q-btn flat color="primary" :label="t('auth.resendOtp')" @click="handleResend" :loading="isResending" :disable="isResending || resendCooldown > 0"
   - If resendCooldown > 0, show countdown text

   Link back to login: router-link to /login

2. Script setup:
   - Imports: ref, onMounted, onUnmounted, useRouter, useRoute, useI18n, authApi, useErrorHandler
   - const router = useRouter(); const route = useRoute(); const { t } = useI18n();
   - const { setError, clearError, hasError, errorMessage } = useErrorHandler();

   State:
   const digits = ref(['', '', '', '', '', '']);
   const otpInputs = ref([]); // array of input refs
   const isSubmitting = ref(false);
   const isResending = ref(false);
   const resendCooldown = ref(0);
   let cooldownTimer = null;

   Computed:
   const loginInfoId = computed(() => route.query.id || '');
   const redirectPath = computed(() => route.query.redirect || '/dashboard');

   Auto-focus first input on mount:
   onMounted(() => {
     if (otpInputs.value[0]) {
       otpInputs.value[0].focus();
     }
   });

   Cleanup cooldown timer:
   onUnmounted(() => {
     if (cooldownTimer) clearInterval(cooldownTimer);
   });

   onDigitInput(index, event):
   - Get the input value
   - If valid digit (0-9):
     - Set digits.value[index] = value
     - If index < 5, focus next input: otpInputs.value[index + 1]?.focus()
     - If all 6 digits filled, call handleSubmit()
   - If not valid, clear the input

   onKeyDown(index, event):
   - If Backspace and current input empty and index > 0:
     - Focus previous input: otpInputs.value[index - 1]?.focus()
   - If ArrowLeft and index > 0: focus previous
   - If ArrowRight and index < 5: focus next

   onPaste(event):
   - event.preventDefault()
   - Get clipboard text
   - Filter to digits only
   - Fill digits array with up to 6 characters
   - If 6 digits, auto-submit

   handleSubmit async:
   - const otp = digits.value.join('')
   - if (otp.length !== 6) return
   - clearError()
   - isSubmitting.value = true
   - try {
       await authApi.verifyOtp(loginInfoId.value, otp);
       router.push(redirectPath.value);
     } catch (err) {
       setError(err);
       // Clear digits on error
       digits.value = ['', '', '', '', '', ''];
       otpInputs.value[0]?.focus();
     } finally {
       isSubmitting.value = false;
     }

   handleResend async:
   - Note: Resend requires calling login again. Since we don't have stored credentials,
     show message to go back to login page. OR if stored in session storage, use those.
   - For simplicity, redirect back to login with a message
   - isResending.value = true
   - Start 60 second cooldown
   - try { /* For now, just start cooldown - actual resend needs credentials */ }
   - resendCooldown.value = 60
   - cooldownTimer = setInterval(() => {
       resendCooldown.value--;
       if (resendCooldown.value <= 0) clearInterval(cooldownTimer);
     }, 1000);

3. Styles (scoped):
   .otp-digit {
     width: 50px !important;
   }
   .otp-digit input {
     text-align: center;
     font-size: 24px;
     font-weight: bold;
   }

Note on resend: The spec says "Resend OTP link (calls login again)" but we don't have stored credentials on OTP page. The practical approach is:
- Option A: Store credentials temporarily in sessionStorage during login flow
- Option B: Redirect back to login page to re-enter credentials
For this implementation, use Option B: Show a link/button that redirects to login with a message that they need to log in again to resend.
