  <name>Task 2: Create ResetPasswordPage.vue</name>
  <files>src/frontend/src/pages/auth/ResetPasswordPage.vue</files>
  <action>
Create the ResetPasswordPage component for setting a new password.

**Route:** `/reset-password?key=xxx`
**Requirements:**
- Get reset key from route.query.key
- New password input (required, 5-50 chars)
- Confirm password input (required, must match)
- Password visibility toggles (like RegisterPage)
- Submit button with loading/disable states
- Success redirects to /login with success message
- Handle invalid/expired key errors
- Show error if key is missing

**Template structure:**
```
q-page > div.col-12.col-sm-8.col-md-6.col-lg-4 > q-card
  - Header: t('auth.resetPassword')
  - Error banner if no key: "Invalid or missing reset key"
  - Form (v-if key exists):
    - q-input for password with visibility toggle
    - q-input for confirmPassword with visibility toggle
    - Error banner for API errors
    - Submit button: t('auth.resetPassword')
  - Link to /login
```

**Script setup:**
- Import: ref, useRouter, useRoute, useQuasar, useI18n, accountApi, useErrorHandler
- Get key from route.query.key
- form ref: { password: '', confirmPassword: '' }
- isPwd, isPwd2 refs for visibility toggles
- isSubmitting ref
- Validation rules:
  - required
  - minLen5: val => val.length >= 5 || t('validation.minLength', { min: 5 })
  - maxLen50: val => val.length <= 50 || t('validation.maxLength', { max: 50 })
  - passwordMatch: val => val === form.value.password || t('validation.passwordMatch')
- handleSubmit async function:
  1. clearError(), set isSubmitting true
  2. Call accountApi.resetPassword(key, form.password)
  3. On success: show $q.notify positive with t('success.passwordReset'), router.push('/login')
  4. On error: setError(err)
  5. Finally: isSubmitting = false

**Key missing handling:**
If !route.query.key, show an error banner and hide the form.

<task type="auto">
  <name>Task 3: Create ActivatePage.vue</name>
  <files>src/frontend/src/pages/auth/ActivatePage.vue</files>
  <action>
Create the ActivatePage component that auto-activates on mount.

**Route:** `/activate?key=xxx`
**Requirements:**
- Get activation key from route.query.key
- Auto-call activate API on mount (no form submission)
- Show loading state during activation
- Success: show message, auto-redirect to /login after 3 seconds
- Error: show error message with link to resend activation
- Handle invalid/expired key
- Use onUnmounted to clear timer

**Template structure:**
```
q-page.flex.flex-center > div.col-12.col-sm-8.col-md-6.col-lg-4 > q-card
  - Header: t('auth.activateAccount')
  - Content based on state:
    - isLoading: q-spinner-dots with t('common.loading')
    - isSuccess: q-banner bg-positive with t('success.activated'), "Redirecting in {seconds}..."
    - hasError: q-banner bg-negative with error message, link to /login
  - No key: error banner "Invalid or missing activation key"
```

**Script setup:**
- Import: ref, onMounted, onUnmounted, useRouter, useRoute, useI18n, accountApi, useErrorHandler
- Get key from route.query.key
- isLoading ref: true (start loading immediately)
- isSuccess ref: false
- countdown ref: 3 (seconds until redirect)
- redirectTimer ref: null (for cleanup)
- handleActivation async function (called in onMounted):
  1. If no key, set isLoading = false, return (error will show due to no key)
  2. Try: await accountApi.activate(key)
  3. On success: isSuccess = true, isLoading = false, start countdown timer
  4. On error: setError(err), isLoading = false
- Countdown logic:
  - setInterval every 1000ms: countdown--
  - When countdown reaches 0: router.push('/login')
  - Store interval in redirectTimer
- onMounted: call handleActivation()
- onUnmounted: if redirectTimer, clearInterval(redirectTimer)

**Important:** The API call happens automatically on mount, not via form submission. Show q-spinner-dots during the API call.
  </action>

  <done>ActivatePage auto-activates on mount, shows countdown on success, auto-redirects to login, properly cleans up timer</done>
</task>
