   - No body required

Import the api instance from 'src/boot/axios'. Export the authApi object with all methods.

<task type="auto">
  <name>Task 2: Create account.api.js</name>
  <files>src/frontend/src/api/account.api.js</files>
  <action>
Create the account management API service file with these methods:

1. `register(userData)` - POST to /v1/account/register
   - Body: userData object (full registration DTO)

2. `resendActivation(login, password)` - POST to /v1/account/regislink
   - Query params: { login, password }
   - Body: null (use axios params config)

3. `activate(key)` - POST to /v1/account/activate
   - Query params: { key }
   - Body: null (use axios params config)

4. `requestPasswordReset(loginId, dob, currentEmail)` - POST to /v1/account/reset_password/init
   - Body: { loginId, dob, currentEmail }

5. `resetPassword(key, password)` - POST to /v1/account/reset_password/finish
   - Body: { key, password }

6. `getAccount()` - GET to /v1/account/
   - No body required

Import the api instance from 'src/boot/axios'. Export the accountApi object with all methods.
  </action>
  <verify>File exists and exports accountApi with register, resendActivation, activate, requestPasswordReset, resetPassword, getAccount methods</verify>
