<task type="auto">
  <name>Task 1: Create session manager plugin</name>
  <files>src/frontend/src/plugins/sessionManager.js</files>
  <action>
Create the session manager plugin following spec Section 5.1.

Constants:
- SESSION_WARNING_THRESHOLD = 2 * 60 * 1000 (2 minutes)
- SESSION_CHECK_INTERVAL = 30 * 1000 (30 seconds)
- SESSION_TTL = 15 * 60 * 1000 (15 minutes)

State (use Vue refs for reactivity):
- lastActivityTime (ref) - timestamp of last activity
- showWarning (ref) - boolean, true when under 2 minutes until expiry
- timeUntilExpiry (ref) - milliseconds until session expires
- isRefreshing (ref) - boolean, true during refresh API call
- checkIntervalId - internal timer ID (not reactive)

Functions to export:
- recordActivity() - updates lastActivityTime to Date.now()
- startSessionMonitoring() - starts 30-second interval timer that:
  1. Calculates timeUntilExpiry = SESSION_TTL - (Date.now() - lastActivityTime)
  2. Sets showWarning = timeUntilExpiry < SESSION_WARNING_THRESHOLD and timeUntilExpiry > 0
  3. If timeUntilExpiry <= 0, dispatch 'session:expired' event and call cleanup()
- stopSessionMonitoring() - clears the interval timer
- refreshSession() - async function that:
  1. Sets isRefreshing = true
  2. Calls sessionApi.refresh()
  3. On success: calls recordActivity(), sets showWarning = false
  4. On error: logs error (let axios interceptor handle 401)
  5. Finally: sets isRefreshing = false
- cleanup() - calls stopSessionMonitoring(), resets all state

Import sessionApi from 'src/api/session.api'.

Export all functions and reactive refs (showWarning, timeUntilExpiry, isRefreshing).
  </action>

  </verify>
  <done>
Session manager plugin provides activity tracking, 30-second interval checks, expiry warning state (showWarning), time tracking (timeUntilExpiry), refresh capability, and dispatches session:expired event when session expires.
