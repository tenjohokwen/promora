<task type="auto">
  <name>Task 2: Create SessionWarningDialog component</name>
  <files>src/frontend/src/components/common/SessionWarningDialog.vue</files>
  <action>
Create SessionWarningDialog.vue with:

1. Template:
   - `q-dialog` with v-model bound to internal `dialogVisible` (synced from showWarning)
   - Set `persistent` prop to prevent dismissal by clicking outside
   - `q-card` inside with:
     - `q-card-section` for title using `$t('session.expiring')`
     - `q-card-section` for body with:
       - Message using `$t('session.expiringDesc', { minutes: minutesRemaining })`
       - `q-linear-progress` showing visual countdown (value = minutesRemaining / 2, since warning shows at 2 min)
       - Question using `$t('session.continueQuestion')`
     - `q-card-actions` with `align="right"`:
       - "Logout" `q-btn` flat, calls handleLogout, uses `$t('auth.logout')`, disabled when isRefreshing
       - "Continue Session" `q-btn` color="primary", calls handleRefresh, uses `$t('session.continueSession')`, :loading="isRefreshing", :disable="isRefreshing"

2. Script setup:
   - Import from vue: `ref`, `watch`
   - Import from vue-i18n: `useI18n`
   - Import `useSession` from `src/composables/useSession`
   - Get `{ t }` from useI18n()
   - Destructure from useSession(): `showWarning`, `minutesRemaining`, `isRefreshing`, `handleRefresh`, `handleLogout`
   - Create local `dialogVisible` ref initialized to `showWarning.value`
   - Watch `showWarning` and sync to `dialogVisible`

Why sync dialogVisible: q-dialog v-model needs a writable ref, but showWarning is readonly. Watch keeps them in sync.

Component should be under 80 lines total.
  </action>
