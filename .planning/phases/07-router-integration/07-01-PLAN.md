<task type="auto">
  <name>Task 2: Add navigation guards</name>
  <files>src/frontend/src/router/index.js</files>
  <action>
Add beforeEach navigation guard after Router creation (before return statement).

Guard logic:
1. Check if route requires auth: `to.matched.some(r => r.meta.requiresAuth)`
2. Check if route requires guest: `to.matched.some(r => r.meta.requiresGuest)`
3. Check authentication via cookie: `document.cookie.includes('user=')`

Guard behavior:
- If `requiresAuth && !isAuthenticated`: Redirect to `/login` with `query: { redirect: to.fullPath }`
- If `requiresGuest && isAuthenticated`: Redirect to `/dashboard`
- Otherwise: `next()` to proceed

Implementation pattern from spec section 10.2:
```javascript
Router.beforeEach((to, from, next) => {
  const requiresAuth = to.matched.some(r => r.meta.requiresAuth);
  const requiresGuest = to.matched.some(r => r.meta.requiresGuest);
  const isAuthenticated = document.cookie.includes('user=');

  if (requiresAuth && !isAuthenticated) {
    next({ path: '/login', query: { redirect: to.fullPath } });
    return;
  }

  if (requiresGuest && isAuthenticated) {
    next('/dashboard');
    return;
  }

  next();
});
```
  </action>

Review index.js - should have Router.beforeEach with auth/guest redirect logic.
  </verify>
  <done>
Navigation guards redirect unauthenticated users to login (with return URL) and authenticated users away from guest pages.
  </done>
</task>
