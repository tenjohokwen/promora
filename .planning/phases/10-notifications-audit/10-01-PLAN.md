  <name>Task 1: Create AccountChangeEventListener</name>
  <files>src/main/java/com/softropic/promora/security/audit/listener/AccountChangeEventListener.java</files>
  <action>
Create AccountChangeEventListener in the security/audit/listener package following the SecurityAuditListener pattern.

The listener must:
1. Be a @Component with @Slf4j annotation
2. Constructor-inject: TrailService, ApplicationEventPublisher, @Value("${baseurl}") String baseUrl, @Value("${server.port}") String serverPort
3. Have @EventListener method `handleAccountChange(AccountChangeEvent event)` that:
   a. Logs the event action at INFO level
   b. Calls recordAuditTrail(event)
   c. Calls sendNotificationEmail(event)

recordAuditTrail() method:
- Create AuditTrail object following SecurityAuditListener pattern exactly
- Use RequestMetadataProvider.getClientInfo() for request metadata
- Set eventTimestamp from ClockProvider.getClock().instant()
- Set msg as "PROFILE_CHANGE: %s".formatted(event.getAction())
- Set login from event.getRecipient().getEmail()
- Set authenticated to true (profile changes require auth)
- Set relevantProperties with Map containing: action, oldValue (null-safe), newValue (null-safe)
- Set userAgent, ipAddress, clientId, browserCookie, url, sessionId from clientInfo
- Set logId using ShortCode.shortenInt(UUID.randomUUID().hashCode())
- Call trailService.recordTrail(auditTrail)
- Wrap in try-catch with error logging (follow SecurityAuditListener pattern)

sendNotificationEmail() method:
- Generate helpCode using ShortCode.shortenInt(UUID.randomUUID().hashCode())
- Build data Map with: helpCode, baseUrl (combine baseUrl + port), action (event.getAction().name()), oldValue (null-safe empty string), newValue (null-safe empty string)
- Create Envelope with:
  - List.of(event.getRecipient())
  - EmailTemplate.PROFILE_CHANGE
  - LocalDateTime.now(ClockProvider.getClock()).plusDays(7) for expiry
  - data map
  - helpCode
- Publish envelope via publisher.publishEvent(envelope)
