<task type="auto">
  <name>Task 2: Create error handler utility</name>
  <files>src/frontend/src/utils/errorHandler.js</files>
  <action>
Create the error parser utility at src/frontend/src/utils/errorHandler.js.

First create the utils directory if it doesn't exist: src/frontend/src/utils/

Implement these functions following spec Section 7.3:

1. parseApiError(error) - Main parser function:
   - Extract from error.response.data (axios error structure)
   - Return object with:
     - helpCode: string | null (from response.data.helpCode)
     - errorKey: string (from response.data.errorMsg?.errorKey or derive from status)
     - message: string (from response.data.errorMsg?.message or default)
     - fieldErrors: object (convert array to { fieldName: message })
     - isValidationError: boolean (errorKey starts with 'validation.')
     - status: number (from response.status)
   - Handle missing response (network error): return generic.network error
   - Handle missing errorMsg: derive from HTTP status code
   - Default error keys by status:
     - 400: 'validation.badRequest'
     - 401: 'security.unauthorized'
     - 403: 'security.opForbidden'
     - 404: 'generic.notFound'
     - 500+: 'generic.unknown'

2. isValidationError(error) - Check if validation error:
   - Call parseApiError, check isValidationError flag

3. getFieldError(error, fieldName) - Get specific field error:
   - Parse error, look up fieldName in fieldErrors, return message or null

4. getFieldErrors(error) - Get all field errors:
   - Parse error, return fieldErrors object

5. getErrorMessage(error) - Get main error message:
   - Parse error, return message

6. getHelpCode(error) - Get help code:
   - Parse error, return helpCode

Export all functions as named exports.
  </action>

  </verify>
